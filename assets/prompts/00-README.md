# Asset Prompts — Cosmic Mart

These files contain descriptions and copy-paste prompts for regenerating or extending the
visual assets used in the Cosmic Mart dashboard. Give each file to Copilot Designer,
DALL·E, Midjourney, or a similar image-generation tool.

---

## Files

| File | Asset | Use |
|---|---|---|
| `01-logo-brand-mark.md` | Compass rose logo | Header, slides, print |
| `02-sector-map-central-graphic.md` | North American celestial trade map | Hero graphic below header |
| `03-agent-icons.md` | 7 agent sigil icons (crescent, sun, arcs, bars, document, orbital, arrow) | Inline agent labels throughout dashboard |
| `04-slide-background.md` | Deep navy + brass nebula slide background | Presentation backgrounds |

---

## How to use

1. Open the `.md` file for the asset you need.
2. Copy the **Copilot prompt** section at the bottom.
3. Paste into Copilot Designer (or your preferred tool) and generate.
4. If the result is close but not quite right, refer to the **Visual description** section
   for specific details to refine with a follow-up prompt.

## Style notes

All assets share the **antique celestial atlas** aesthetic: deep navy backgrounds, warm brass
line work, cream ink. Line-art only — no gradients within icons, no fills on strokes, no
drop shadows. The mood is precise, measured, slightly antique. Think 17th-century
astronomical charts rendered as a modern UI.
